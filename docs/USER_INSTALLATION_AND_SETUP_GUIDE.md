# NOLA SMS Pro User Knowledge Base

For first-time users, agency installers, sub-account users, and beta testers.

NOLA SMS Pro is installed from the HighLevel Marketplace. Users do not need to
download a desktop or mobile app. Installation means authorizing NOLA SMS Pro
for a HighLevel sub-account, creating or signing in to a NOLA SMS Pro account,
and confirming that the correct location is connected.

This guide is structured like the user documentation sidebar:

- Welcome
- Getting Started
- Using NOLA SMS Pro
- Troubleshooting and Beta Testing

---

## Welcome

Welcome to NOLA SMS Pro.

NOLA SMS Pro helps businesses send SMS messages from inside HighLevel. It lets
users manage contacts, create reusable SMS templates, send individual or bulk
messages, review delivery history, monitor SMS credits, and manage Sender IDs.

Use this documentation when you need to:

- install NOLA SMS Pro from the HighLevel Marketplace;
- connect the correct HighLevel sub-account;
- create or access your NOLA SMS Pro account;
- configure account, Sender ID, notification, and credit settings;
- send your first SMS; or
- troubleshoot common setup and sending issues.

# Getting Started

## 1. Introduction

NOLA SMS Pro runs inside HighLevel after it has been installed for a selected
sub-account/location.

A normal first-time setup has four parts:

1. Install NOLA SMS Pro from the HighLevel Marketplace.
2. Choose the correct HighLevel sub-account/location.
3. Create or sign in to your NOLA SMS Pro account.
4. Confirm the dashboard, Sender ID, and credits before sending SMS.

For beta testing, use a test sub-account first. Do not use a real client
account until installation, setup, and test sending have been confirmed.

## 2. Quickstart

Use this quickstart if you already have access to HighLevel and only need the
short version.

1. Log in to HighLevel.
2. Go to **Agency View**.
3. Open the **Marketplace**.
4. Search for **NOLA SMS Pro**.
5. Click **Install**.
6. Select one test sub-account/location.
7. Review the permissions and click **Allow & Install**.
8. Create your NOLA SMS Pro account or sign in to the existing owner account.
9. Open NOLA SMS Pro from the HighLevel sub-account menu.
10. Check **Settings**, **Sender ID**, and **SMS Credits**.
11. Add a test contact.
12. Send one natural test SMS.
13. Confirm the message status in message history.

For the first test, select only one sub-account. Do not install to all
sub-accounts until the first location works correctly.

## 3. Installation & Setup

### Before You Start

Make sure you have:

- access to your HighLevel agency account;
- permission to install Marketplace apps;
- the correct sub-account/location where NOLA SMS Pro should be installed;
- an email address for your NOLA SMS Pro account;
- a phone number for your profile; and
- SMS credits if you are ready to send a test message.

### Open the Marketplace

1. Log in to HighLevel.
2. Go to **Agency View**.
3. Open the **Marketplace**.
4. Search for **NOLA SMS Pro**.
5. Click **Install**.

### Choose the Sub-Account

HighLevel will ask where the app should be installed.

1. Search for the correct sub-account/location.
2. Select only the sub-account you want to use.
3. Click **Continue**.

For first-time testing, choose one test location so it is easy to confirm that
the installation is connected to the correct workspace.

### Confirm the Installation

Before approving the installation, check that:

- the app name is **NOLA SMS Pro**;
- the selected location is correct; and
- the requested permissions look correct for SMS, contacts, and account access.

Then click **Allow & Install**.

HighLevel may show NOLA SMS Pro inside the sub-account immediately after this
step. That is normal. If setup is not complete, the app should guide you to
continue setup, sign in, or reconnect instead of showing the full dashboard.

### Create or Sign In to Your NOLA SMS Pro Account

After installation, you should be redirected to NOLA SMS Pro.

For a new install, enter:

- full name;
- email address;
- phone number;
- password; and
- password confirmation.

Then click **Create Account**.

Use the same email and password when you need to log in again.

If the location was already installed before, you may see a sign-in page
instead of a registration page. Sign in with the existing owner account. Do not
create a second owner account for the same location unless instructed by
support.

## 4. Configure Account

After your account is created or you have signed in:

1. Go back to HighLevel.
2. Open the same sub-account/location.
3. Find **NOLA SMS Pro** in the left menu.
4. Click it.
5. Wait for any loading or verification screen to finish.

You should then see the NOLA SMS Pro dashboard.

Open **Settings** and confirm:

- your name;
- your email address;
- your phone number;
- the connected location/sub-account name;
- the connected agency/company name;
- notification preferences; and
- billing or credit access, if available for your role.

If the wrong location or account appears, stop testing and take a screenshot.
Do not send SMS from the wrong workspace.

## 5. Dashboard Overview

The dashboard is the main workspace after setup is complete.

Use the dashboard to check:

- recent SMS activity;
- available SMS credits;
- message status summaries;
- recent contacts or conversations;
- pending Sender ID requests;
- alerts or notifications; and
- shortcuts to common actions.

The full dashboard should only be usable after setup or login is complete. If
the dashboard opens before account setup is complete, record it as an issue.

## 6. Integration

NOLA SMS Pro connects to HighLevel through the Marketplace installation.

The integration allows NOLA SMS Pro to:

- open inside the selected HighLevel sub-account;
- identify the connected agency and location;
- access eligible HighLevel contacts;
- send SMS using the configured sender;
- record message history; and
- keep the user in the correct workspace after refresh or login.

If the app shows a reconnect message, click the reconnect button and follow the
instructions. Do not register a new owner account unless the app specifically
asks you to create one for a fresh install.

# Using NOLA SMS Pro

## Contacts

Open **Contacts** to view or add contacts.

For a first test, add a test contact with:

- name; and
- valid Philippine mobile number.

Recommended format:

```text
09XXXXXXXXX
```

After saving, search for the contact to confirm it appears in the contact list.

If contacts do not appear, confirm that you are in the correct HighLevel
location and that the app is fully connected.

## SMS Templates

Open **Templates** to create reusable messages.

Create a simple template with:

- template name;
- category; and
- message body.

Save the template, then confirm it is available when composing an SMS.

Avoid using only generic test words such as:

- `test`
- `sms test`
- `test message`

Some SMS providers may reject messages that look spam-like. Use a natural test
message instead:

> Hi, this is a delivery test from NOLA SMS Pro. No reply is required.

## Sending SMS

Open **Compose** or the SMS sending screen.

1. Select your test contact or enter the mobile number.
2. Use the default sender for the first test.
3. Type a natural test message.
4. Review the character count and estimated credits.
5. Click **Send** once.
6. Wait for the result.

After sending, open message history or the related conversation and check the
status.

The message may show as:

- **Sending**
- **Sent**
- **Failed**

If the message fails, do not keep clicking send. Take a screenshot of the error
and check message history before trying again.

## Sender ID

Open **Settings > Sender IDs**.

For the first test, use the default sender:

```text
NOLASMSPro
```

If you need a custom Sender ID, click **Request New** and submit the required
details. A custom Sender ID may need approval before it can be used.

Only approved Sender IDs should be used for sending. Pending or rejected Sender
IDs should not be selected for live messages.

## SMS Credits & Billing

Open **Settings > Credits** or **Billing**, depending on your account view.

Check that you can see:

- available credits;
- credits used today;
- monthly usage;
- transaction history; and
- purchase or request-credit options, if enabled for your role.

If credits do not appear, refresh once. If they still do not appear, record a
screenshot before continuing.

Do not send live messages if the credit balance looks incorrect.

## Message History

Use message history to confirm what happened after sending.

Message history should show:

- recipient;
- sender;
- message content or preview;
- send time;
- current delivery status;
- credits used; and
- any error details if sending failed.

If a message remains stuck in **Sending**, wait a short time and refresh the
history. If it still does not update, take a screenshot and report the issue.

## Reports & Analytics

Use reports and analytics to review SMS activity over time.

Depending on your account access, reports may include:

- total messages sent;
- successful messages;
- failed messages;
- credit usage;
- sender activity;
- contact or campaign activity; and
- date-based filtering.

For beta testing, confirm that sent messages and credit usage appear in reports
after a test SMS is sent.

## Settings

Use **Settings** to manage account and workspace configuration.

Common settings include:

- profile information;
- connected HighLevel location details;
- notification preferences;
- Sender IDs;
- SMS credits and billing;
- support requests; and
- account access options.

If any setting shows the wrong agency, location, email, or phone number, stop
and report the issue before sending SMS.

# Troubleshooting and Beta Testing

## Interrupted Installation

Sometimes a user may close the browser or lose connection during setup.

### Closed Before Clicking Allow & Install

The app should not be installed yet. Start again from the HighLevel
Marketplace.

### Closed After Clicking Allow & Install

HighLevel may already show NOLA SMS Pro in the sub-account.

Open NOLA SMS Pro again from the sub-account menu. The app should guide you to
continue setup, sign in, or reconnect.

It should not show the full dashboard until setup is complete.

### Closed on the Registration Page

Open NOLA SMS Pro again from HighLevel and continue setup.

Do not create multiple accounts for the same location.

### Reconnect Message Appears

Click the reconnect button and follow the instructions.

Do not register a new owner account unless the app specifically asks you to
create one for a fresh install.

## Uninstall NOLA SMS Pro

If you need to remove NOLA SMS Pro:

1. Go to HighLevel Marketplace or the installed apps area.
2. Find **NOLA SMS Pro**.
3. Choose **Uninstall** or remove the app from the selected location.

After uninstalling, NOLA SMS Pro should no longer allow SMS sending for that
location.

## Beta Test Checklist

Use this checklist during a beta test.

- [ ] I installed NOLA SMS Pro into the correct test sub-account.
- [ ] I was redirected to account setup or login.
- [ ] I created or signed in to the correct NOLA SMS Pro account.
- [ ] NOLA SMS Pro opened inside the correct HighLevel location.
- [ ] Settings showed the correct name, email, agency, and location.
- [ ] The default sender `NOLASMSPro` was available.
- [ ] Credits displayed correctly.
- [ ] I created a test contact.
- [ ] I created or used a message template.
- [ ] I sent one natural test SMS.
- [ ] The message status appeared in message history.
- [ ] Credits changed correctly after sending.
- [ ] Refreshing the app kept me in the same correct location.

If any item fails, take a screenshot and write down:

- what you clicked;
- what you expected;
- what actually happened;
- the location/sub-account name; and
- the time of the issue.

## Important Beta Testing Rule

If NOLA SMS Pro appears in HighLevel immediately after **Allow & Install**, that
does not always mean setup is finished. This is normal Marketplace behavior.

For a successful test, the full NOLA SMS Pro dashboard should only be usable
after account setup or login is complete.
